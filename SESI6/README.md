# SESI 6 - API Testing
Folder ini berisi materi dan tugas untuk sesi 6 yang berfokus pada API Testing menggunakan Postman, mencakup pembuatan request dasar, assertion, serta export collection.

# isi:
- File collection Postman hasil export (.json)
- README sesi 6

# Ringkasan Materi:
- Pengenalan API Testing dan fungsinya dalam pengujian aplikasi
- Instalasi Postman untuk membuat dan mengelola request
- Penggunaan method CRUD (GET, POST, PATCH, DELETE)
- Pembuatan dan pengaturan Collection
- Penggunaan Environment Variable
- Dasar JSON Schema Validation
- Cara melakukan sharing Collection

# Scope Tugas:
1. Membuat collection di Postman dengan format nama: "Nama-Batch12"
2. Membuat sample request API menggunakan URL: https://reqres.in/
- 1 request GET
- 1 request POST
- 1 request PATCH
- 1 request DELETE
3. Menambahkan minimal 1 asser di setiap request
4. Melakukan export collection dalam format .json

# Tujuan Pembelajaran:
- Memahami konsep dasar API Testing
- Menggunakan Postman untuk membuat dan menguji API endpoint
- Mengelola collection dan environment variable
- Menerapkan assertion sederhana pada setiap request
- Mengekspor hasil pengujian dalam bentuk collection
